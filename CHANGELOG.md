# Changelog

## 1.0.0 — 2026-10-20

Initial standalone release.

- Adds conditional logic controls to supported Pro Elements classic Form fields.
- Supports Show/Hide actions, ALL/ANY rules, nested dependencies, text/number/choice/acceptance comparisons, and Clear/Retain hidden-value policies.
- Adds frontend initialization for multiple, dynamically inserted, and popup forms.
- Adds initial server-side visibility, hidden-required validation handling, and Clear-policy record cleanup while preserving unrelated validation errors and configured form actions.
- Adds dependency/runtime/API checks, administrator notices, compatibility/installation documentation, and isolated automated tests.
- Real WordPress + Elementor + Pro Elements installation testing remains outstanding; see [TESTING.md](TESTING.md).
